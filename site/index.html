Two products, one ledger

Use either on its own. Together they cover what an unattended agent can spend and what it can touch.

reins budget

Budget governor

Meters spend per agent per period and picks a tier from what is left.

  • Steps the model down. Opus while the budget is healthy, Sonnet in the middle, Haiku near the floor.
  • Slows the heartbeat. A multiplier your loop applies to its sleep. Four times slower in low, eight in critical.
  • Stops idle loops. Three read only turns in a row and the decision is sleep.
  • Halts at zero. Dead after a grace period. The proxy returns 402, the adapters throw.
reins govern

Governance ledger

A policy check before every tool call and a record after it.

  • Policy engine. Protected paths, blocked commands, denied tools, approval tools, rate limits and spend caps that actually deny.
  • Hash chained ledger. Append only SQLite. reins ledger verify finds the first broken event.
  • Evidence pack. One HTML file per period, mapped to SOC 2, ISO 27001, NIST AI RMF and the EU AI Act.
  • Nothing leaves the machine. No telemetry, no account, no upload.

How a turn flows

Every model call and every tool call passes the same six points. Each one writes to the ledger.

continue, allow sleep, approve stop, deny

Four ways in

Pick the one that matches how your agent runs. All four write to the same ledger.

No code change. Point any runtime at the proxy and read the tier from the response headers.

reins proxy --port 4141

ANTHROPIC_BASE_URL=http://localhost:4141 node agent.js
OPENAI_BASE_URL=http://localhost:4141/v1 python agent.py

# response headers
x-reins-tier: normal
x-reins-remaining-usd: 14.20
x-reins-model: claude-sonnet-5

# when the agent is dead
HTTP/1.1 402
{ "error": "budget_exhausted", "state": { "tier": "dead", ... } }

Wrap the client. Decide, substitute, clamp and record happen around messages.create, streaming included.

import Anthropic from '@anthropic-ai/sdk';
import { Reins } from 'reins';
import { withReins } from '@reins/adapters';

const reins = Reins.open();                 // reads reins.yml
const client = withReins(new Anthropic(), reins);

const msg = await client.messages.create({
  model: 'claude-opus-5',                   // substituted by tier
  max_tokens: 4096,                         // clamped by tier
  messages: [{ role: 'user', content: 'Summarise the overnight logs.' }],
});

// before a tool runs
const v = reins.policy.check({ tool: 'Bash', input: { command } });
if (v.verdict === 'deny') throw new Error(v.reason);

Middleware for wrapLanguageModel. Works with any provider the AI SDK supports.

import { wrapLanguageModel, generateText } from 'ai';
import { anthropic } from '@ai-sdk/anthropic';
import { Reins } from 'reins';
import { reinsMiddleware } from '@reins/adapters';

const reins = Reins.open();
const model = wrapLanguageModel({
  model: anthropic('claude-sonnet-5'),
  middleware: reinsMiddleware(reins),
});

const { text } = await generateText({ model, prompt: 'Triage the inbox.' });
